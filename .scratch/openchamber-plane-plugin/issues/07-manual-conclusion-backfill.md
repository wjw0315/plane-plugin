# 07 手动回填结论：草稿 → 写评论 → ✓ 标记

## Parent

[OpenChamber Plane 扩展 Spec](../spec.md)

## What to build

把会话的成果写回任务。详情里「回填结论…」开一个草稿抽屉，内容是纯文本、可编辑，确认后作为评论追加到这张工作项，首行标明来自哪个会话。写成功后详情里出现结论正文与「已回填」时间，卡片上出现「✓ 结论」标记；写失败保留草稿并给重试，抽屉不关。

只追加评论，不改描述——原描述是人工维护的需求文本。

## Acceptance criteria

- [ ] 详情里能开草稿抽屉，草稿可编辑；空草稿时「写入评论」不可点
- [ ] 写入后 Plane 侧出现一条评论（用假 Plane 断言 POST 到评论路径、body 是 HTML 段落、首行带会话来源）
- [ ] 成功后卡片出现「✓ 结论」，详情显示结论正文与时间
- [ ] 写入失败：抽屉不关、草稿还在、出现重试；重试成功后标记才出现
- [ ] 对同一张卡从同一个会话重复回填，先提示「这张卡已回填过」
- [ ] 回填不改动原描述（假 Plane 里断言没有 PATCH 描述）
