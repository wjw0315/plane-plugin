# 05 详情：覆盖页 / 就地展开

## Parent

[OpenChamber Plane 扩展 Spec](../spec.md)

## What to build

点卡片能看全一张卡：标题、编号、状态（可直接切）、优先级、指派人、标签、描述、关联会话（本片只读占位）。动作是切状态、在 Plane 打开、复制链接、关闭。

形态跟视图走：「列」视图用面板内覆盖式二级页（左滑入，返回后看板位置与滚动不变）；「列表」视图就地展开在卡片下方，再点同一张卡收起。两种形态字段与动作完全一致。打开详情时先用列表已有数据秒开，同时拉一次单条最新覆盖渲染；单条失败只提示「可能不是最新」，不挡着看。

## Acceptance criteria

- [ ] 列视图点卡片：覆盖层滑入，列表节点没被销毁，返回后滚动位置不变
- [ ] 列表视图点卡片：详情展开在卡片内；再点同一张完全收起
- [ ] 两种形态的字段与按钮一致（可用同一份断言清单跑两遍）
- [ ] 详情里切状态：看板与详情同时更新，且只发一次改状态请求
- [ ] 「在 Plane 打开」用宿主能力打开正确的 issue 地址（含项目标识与序号）
- [ ] Escape、返回箭头、点空白遮罩都能关闭；关闭后键盘焦点回到原卡片
- [ ] 单条详情请求失败：仍显示列表数据，并提示内容可能不是最新
